AI Prompt URL Generator

プロンプトをURLエンコードし、ChatGPT / Grok 用のURLとHTMLリンクを生成します。

```
入力文字数
0
ChatGPT URL
0
Grok URL
0
URL上限
2,000
```
```

ChatGPT

プロンプトを入力してください。
URL長：0 / 2,000
<a>タグを生成します。
```
```

Grok

プロンプトを入力してください。
URL長：0 / 2,000
<a>タグを生成します。
```

※ URL長は、URLエンコード後のクエリを含む「完成したURL全体」の文字数で判定しています。 安全側の基準として2,000文字を上限としています。
